# NomadDeck

A cyberdeck dediacted to cybersecurity tools and coding, built to work from anywhere.

# SPEC

- SBC : Raspberry Pi 5
- OS : Kali Linux ARM
- Battery : LiPo 3000-5000mAh + charge/BMS module, multi-rail power (5V / 3.3V regulated separately)
- Display : ~6" LCD, HDMI/DSI driver board
- Hinge : 3D-printed
- Keyboard : custom PCB, compact layout with Fn/Shift layers, simple backlighting (no addressable RGB)
- Pointing device : trackpoint (analog joystick, ADC input)
- Extension ports : USB-A + USB-C + exposed GPIO header, front-facing
- Enclosure : 3D-printed, two-part (top/bottom)
- Budget target : < 200 EUR

# FEATURES

- Full Linux environment for on-device pentesting and coding
- Pre-installed security toolset (Kali)
- Custom compact keyboard with layered input (Fn/Shift)
- Trackpoint for cursor control without extra footprint
- Simple backlit keys
- Battery-powered, portable, no external power required for typical sessions
- Expansion-ready via exposed USB-A and GPIO header (external radio modules can be added later — WiFi monitor mode adapter, SDR dongle)
- 3D-printed enclosure with hinged lid
