# NomadDeck

A cyberdeck dediacted to cybersecurity tools and coding, built to work from anywhere.

# SPEC

- SBC : Raspberry Pi Compute Module 5, 4 GB RAM, Wi-Fi, Lite
- OS : Kali Linux ARM
- Display : ~8" IPS LCD, 1280×800, HDMI
- Battery : ~15–20 Wh LiPo battery
- Power : Custom power management with USB-C charging and regulated 5V / 3.3V rails
- Keyboard : Custom PCB, compact layout with Fn layers and simple backlighting
- Keyboard MCU : RP2040
- Pointing device : Analog joystick / trackpoint controlled through the RP2040
- Mainboard : Custom CM5 carrier board
- Cyber I/O: USB-A, USB-C, GPIO, UART, SPI and I²C expansion
- Storage : microSD
- Enclosure : Custom 3D-printed two-part enclosure with hinged display
- Hinge : 3D-printed/custom hinge
- Cooling : Active cooling for the CM5
- Target weight : As low as reasonably possible
- Budget : < 200 EUR

# FEATURES

- Full Linux environment for cybersecurity and programming
- Kali Linux ARM with access to a large cybersecurity toolset
- Portable, battery-powered operation
- Custom mechanical keyboard with programmable Fn layers
- Integrated trackpoint for mouse control without requiring a separate mouse
- Simple integrated keyboard backlighting
- Custom CM5 carrier board designed specifically for the NomadDeck
- Dedicated cyber expansion interfaces through USB, GPIO, UART, SPI and I²C
- External USB devices can be connected for additional capabilities such as compatible Wi-Fi adapters or SDRs
- Battery monitoring and dedicated power management
- USB-C charging
- Hinged 8" display for a compact laptop-style form factor
- Modular architecture allowing additional hardware modules to be added later
- Fully 3D-printed enclosure
- Open-source hardware and software design
- Designed to be repairable and upgradeable rather than being a closed system
